# Task-Record-and-Tracker
Use this system for requests gathering and record as task, with following up on tasks status. It is useful for BA/Business Users/Developer to track tasks.
## Front-End Plan: Head title, requirement gathering form bottom, next page bottom,task review page including : Assignee, Title, Description, Status, Target Finish Date
## Back-End Plan:gathering form including these data: Request Category, Request Title, Request description, Requestor,Comments
